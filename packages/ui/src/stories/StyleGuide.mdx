## Best Practices

### DO ✓

- Use monospace fonts exclusively
- Keep borders flat (radius: 0)
- Apply consistent spacing (4px base unit)
- Use uppercase for technical labels
- Abbreviate status codes (3-4 chars)
- Show keyboard shortcuts in brackets
- Provide hover tooltips for abbreviations
- Use text-based loading indicators
- Keep animations ≤150ms

### DON'T ✗

- Use icons or emojis
- Add box shadows or gradients
- Round corners on any element
- Mix sans-serif fonts
- Create long abbreviations (>4 chars)
- Use spinners or circular progress
- Animate layout shifts
- Create transitions >150ms
- Use decorative elements
